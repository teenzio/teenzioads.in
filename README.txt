# Teenzio Ads Website

Open `index.html` in a browser to preview the site.

## Structure
- index.html — homepage
- projects/teenzio-motion.html — Motion project page
- projects/teenzio-vista.html — Vista project page
- projects/digital-marketing.html — Digital Marketing project page
- css/style.css — all styling
- js/main.js — menu, reveal animations, form demo
- images/teenzio-logo.png — uploaded Teenzio logo

## Before deployment
1. Replace the CSS-generated project visuals with real Teenzio project photos/videos when available.
2. Replace `hello@teenzio.ads` with the real company email.
3. Connect the contact form to Formspree, Web3Forms, a backend API, or your preferred email service.
4. Update project text once the service details are finalized.

## Fonts
Space Grotesk for headings and Inter for body text, loaded from Google Fonts.
